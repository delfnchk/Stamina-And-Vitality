# Stamina And Vitality — Minecraft 1.21.1 NeoForge

Replaces hunger with a centered stamina system from Lololoshka's Heart of the Universe season to minecraft. Sprinting, attacking, building, and much more now require stamina. Animated hearts and recovery trails.

Заменяет механику голода на сбалансированную систему выносливости, как в сезоне «Сердце Вселенной» у Lololoshka. Теперь для бега, атаки, строительства и многих других действий требуется выносливость. Добавлены анимированные сердечки и визуальные эффекты восстановления.
